## Rules Before Building New Features
- Do not start advanced features before MVP basics are stable
- Do not add complexity without clear product value
- Prioritize retention-related features first
- Test each major feature before moving to the next one

## MVP Definition
The MVP is ready when:
- users can sign up
- users can create profiles
- users can create posts
- users can like/comment
- users can ask doubts
- users can view profiles
- aura system works in a basic way
- app is stable enough for first college testing
